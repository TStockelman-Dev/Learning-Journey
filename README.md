# Introduction

This repository serves as the primary location where I document my journey to learn coding, software development, database management, and web development. In a very real sense, this repository serves as a time capsule that documents my growth, successes, and failures. Since it is my goal to never stop learning, it is likely that this repository will be one of the most updated repositories connected to me on GitHub.

This repository contains projects that I have completed through freeCodeCamp, boot.dev, and similar curricula, as well as my own sandbox studies. In this repository, I have only included code that I have written myself. In other words, I have only included code that I have written without tutorials or walkthroughs. That is, if I was told what to write in order to get the project to work, either through a workshop on fCC or a similar source, I have not included it. If I had to figure the program out and write it from the ground up, I have included it. Practically speaking, this means that several workshop projects and similar items have not made it into this repository, although several of them that I have completed through freeCodeCamp may be found on my [freeCodeCamp profile](https://www.freecodecamp.org/tstockelman-dev) by viewing my activity on their site.

Ultimately, this repository shows my growth over time as a developer. It serves as a time machine that allows others to see the lessons that I have learned, the puzzles that I have solves, and how I solved those puzzles. It enables interested parties to see how I have grown, how I think, and how I solve the technological problems that come my way. It also permits me to look back on my own work as I continue to grow so as to remind myself that growth is always possible. It is my hope that this repository can serve as an encouragement for others who may be beginning their own journey, as well. We all start somewhere, and this is the documentation of where my journey begins.

# Recent Milestones

Several key milestones along this journey stand out as important. This section will keep track of several of the most significant.
<ul>
  <li><strong>Feb. 5, 2026</strong>: After two long days of working through the solutions to the Tower of Hanoi algorithm, I finally discovered and programmed an iterative solution to the Tower of Hanoi problem that will solve for any number of starting disks up to 20 in 2^n - 1 moves, and will display the each individual move needed to complete the puzzle, all in 30 seconds or less. Future improvements are planned for this project to reduce the space complexity of the hanoi-solver and to provide additional improvements. The iterative solution to the Tower of Hanoi came from observing the patterns that the individual rings followed as they completed the puzzle in the optimal number of moves. From that moment, it was only a matter of writing a Python script that could solve the Tower of Hanoi by following that exact pattern.</li>
  <li><strong>Feb. 7, 2026</strong>: After completing my the hanoi-solver as my final certification project and passing the Python exam on freeCodeCamp, I have officially earned the freeCodeCamp Python certification. My goal is to remain sharp in Python by improving upon one or two of the projects that I have already completed, as well as working on projects that will help average, everyday people.</li>
